The one-paragraph thesis

A large prompted LLM can do this task, but not in a car: cost, latency, and cabin privacy all argue for on-device. The engineered behaviour lives in a ~1,200-token teacher prompt; fine-tuning distills that behaviour into a 3B model that needs only a ~60-token system prompt. Fine-tuning as prompt compression — measured by schema-pass rate, deterministic safety compliance, and pairwise LLM-judge win-rate against both the base model and a much larger prompted model.
